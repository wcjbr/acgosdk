# Desktop RTM assets

This directory bundles the official Agora JavaScript SDK distributions used by
the desktop loopback bridge:

- `agora-rtm-2.2.1.js` from `agora-rtm-sdk` 2.2.1.
- `agora-rtc-4.22.0.js` from `agora-rtc-sdk-ng` 4.22.0.

Both packages declare the Apache-2.0 license. The files are kept unmodified.
